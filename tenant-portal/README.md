# tenant-portal

The Mutakamel tenant portal, built with Angular 22.

Before changing anything, read `CLAUDE.md` (same content as `AGENTS.md` and `GEMINI.md`) and the design system in `design-system/`.

```bash
pnpm install
pnpm start    # http://localhost:5002
```

See [Unit and mutation tests](tests/README.md) for the test folder layout, module
index, and commands.
