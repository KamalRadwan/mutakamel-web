# Template authoring host

The host composes the element inspector, structured-text editor, controlled field picker, page controller and shared feedback around the existing DesignerCommandStore and interaction controller. Apply enters the existing canonical command history. Local form leases contain pending-state metadata only; they do not contain an authored document, save transport or second undo stack.

## Qualified owner binding

DesignerNativeSource must come from the accepted full R8 owner admission and qualified native entrypoints. Its binding identity includes source key, descriptor version, semantic and full canonical descriptor checksums, owner-context fingerprint and all three exact Schema/Engine/provider pins (name, version, manifest hash, server-root entrypoint hash). The currentIdentity callback is a trusted live reader lookup. Refresh, revocation or replacement must return null or the newly accepted identity immediately, including when the actor/template/draft context key is unchanged. A callback that closes over a permanently accepted response is unsuitable.

The provider clones/freezes the complete descriptor, validates against that full object and compares the current identity before every later admission. A real workspace unmount retires retained providers. StrictMode setup replay keeps the binding alive; equivalent snapshots with the same immutable binding identity retain it even if JavaScript wrappers are reconstructed. A different admission/surface lifetime must receive a different source bindingKey. Package qualification and trusted reader construction remain owner responsibilities; a field-list projection is insufficient.

The editor uses T04's exact separate fetchTemplateOwnerAdmission transport and T03's readTemplateOwnerAdmission helper. Independent loader pins and qualified canonicalJson are supplied before the request. The request captures the actual owner/scope and canonical generation, and its results must agree with the current picker source checksum. Source construction runs after asynchronous admission, outside render. A missing/refusing loader leaves native source absent. R8 does not serialize function definitions or currency/unit membership; optional owner validation context is accepted only from the real qualified owner and is identity-bound. No empty fabricated catalogue, permissive membership callback or raw native-validator coercion fills that gap.

## Local sessions

Unapplied property fields, an active T14 text lease, or the open page-management session fence Save, preview, global Undo/Redo, selection and competing command writers. Each form retains its scoped Apply port; it cannot acquire another form's write scope. T02's Continue/Discard close protocol also sees the T14 text session. T14's actual host interlock remains active after unexpected child unmount, and its stale release cannot clear a later lease. Explicit editor-level discard remounts local forms while preserving canonical draft state/history. Owner replacement disposes local state.

Local reporters and provider lifetimes include the actual command generation. The actual canonical/model/pan/pointer owners register with DesignerInteractionExit. Missing required readers refuse exit; actual unmounted resources are declared by their render owner. X-close, outside close, dirty Discard and first-active Escape consume T20 R6's aggregate binding plus R5's single-state admission. Rich cleanup follows admitted cancellation; the non-DOM gate is never spread onto DialogContent. Pan uses its actual origin/capture state, pointer cancellation uses the actual Moveable instance/capture record, and current tickets are rechecked. The unqualified native renderer declares its genuine lack of model/Handles so bare pan/Hand exit and authorized owner reload do not require a fake controller.

The page-management fence is intentionally conservative because the current T13 port does not publish field-level dirty events. Closing its outer dialog explicitly warns that unapplied fields are discarded while already applied draft changes remain. PageHost captures its authority lifetime, delegates to the same store and qualified native validator, and refuses old-owner forms even if the exact document reference is retained. It also gates read-only page navigation during another local session.

PageHost's source listeners attach at commit, reconnect during StrictMode replay, and retire on real unmount. Reconstructed bridge wrappers update the live bridge without an unconditional publish loop. Authority/read/edit changes notify through a bounded access comparison. The actual T13 R3 interlock and R4 form eligibility consume this façade. Every history/gesture publication reconciles selection before either subscription observes the new document. Canonical page roots must equal the ordered document root index, with distinct page/node IDs and exclusive node ownership.

## Current limits

The legacy element/property editor is absent from the Page tab. Page setup uses T13 when qualified context exists and otherwise reports unavailable. Flow/Hybrid layout-changing page operations require T05's real synchronous assessment; no guessed assessment is supplied. Fit uses the active page's dimensions. T13 guides are not painted over the placeholder canvas: they require the actual native scene/measurement root, as a sibling outside measurement/capture.

T02 R5 eligibility plus R6 feedback and T15 eligibility-r3 share one genuinely qualified host for native Apply, eligibility and both full controlled pickers. Missing DataNative/catalogue/identity qualification supplies no replacement port; stored content stays preserved. T14 R4 retains its real link-draft/raw-Unicode corrections. T18 recovery-only review uses T20's focus host outside native admission; the full properties wrapper is not mounted alongside the existing properties host. Qualified function/identity catalogues, native font metadata and the T06 crop/content-frame port remain explicit owner gates. Semantic heading controls stay disabled until schema, compiler and layout are jointly qualified. This source composition is not authenticated runtime, visual, print or PDF acceptance.
