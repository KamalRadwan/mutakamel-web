## Safety

- All IDs, emails, tokens, keys, and correlation IDs are synthetic.
- Never paste production credentials or personal data into documentation.
- Keep exact endpoint fields aligned with the linked API page.
- A placeholder such as `<access-token>` is not a valid test value.
