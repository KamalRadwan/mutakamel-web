### 1.2 UI/UX Intelligence (`ui-ux-pro-max`) & Tenant/Admin Design System Rules Applied Across Every Row

Per `ui-ux-pro-max` enterprise financial workspace guidance and binding Tenant/Admin Portal rules (`docs/design/README.md`, `accounting-ia.md`, `accounting-status-and-a11y.md`):
1. **Zero Browser Financial Arithmetic:** Monetary fields, balances, tax totals, FX conversions, trial-balance footers, and aging buckets are rendered verbatim from server decimal strings (`string`, formatted via `Intl.NumberFormat` with `ar-EG-u-nu-latn` / `en-US`, `tabular-nums`). `Number()` is never called on a decimal string.
2. **Bilingual (`AR-RTL` / `EN-LTR`) & Logical Properties Only:** Every screen title, tab, column header, filter chip, status badge (`t.status.*`), and empty/error state is authored in both Arabic and English dictionaries with **zero language ternaries** in TSX and logical CSS properties only (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `text-start`, `text-end`).
3. **LTR Islands (`IdentifierText`):** Account codes, journal entry numbers, UUIDv7s, tax registration numbers (TRN/RIN), ETA UUIDs, IBANs, SWIFT/BIC codes, SHA-256 chain hashes, and formatted monetary strings render inside `<IdentifierText>` (`dir="ltr"`, `unicode-bidi: isolate`, `tabular-nums`, Western digits `0–9` in both locales).
4. **Four Outcome Roles & Non-Colour Cues:** Statuses use only `brand`, `positive`, `caution`, `negative`, and `ink` neutral tokens (`accounting-status-and-a11y.md`), paired with icon + localized `t.status.*` text. Debit/credit and negative amounts always carry explicit `DR`/`CR` (`مدين`/`دائن`) or sign/parentheses cues, never colour alone.
5. **Transport, Idempotency & Concurrency:** Every `WRITE_SENSITIVE` mutation sends a fresh `UUIDv7` `x-idempotency-key` (`generateUUIDv7` from `src/lib/uuid.ts`; never `crypto.randomUUID()`). Versioned updates/workflow transitions send `If-Match` / `expectedVersion`. `202 Accepted` responses poll `Location` respecting `Retry-After`.
6. **Separation of Logic & View:** Every screen separates hooks (`hooks/use<ScreenName>.ts`) from pure markup `.tsx` views under ~300 lines, importing UI primitives/patterns exclusively from `@/design-system`.

### 1.3 Prefix Convention in `Endpoints` Column

- All Accounting tenant paths below omit the constant Gateway prefix `/api/tenant/accounting/v1` for compactness unless contrasted with Core; e.g. `GET /accounting/accounts` means **`GET /api/tenant/accounting/v1/accounts`**.
- Core tenant routes write the full canonical path **`/api/tenant/core/v1/...`**.
- Admin Portal routes write the full canonical path **`/api/admin/core/v1/...`** or **`/api/admin/worker/v1/...`**.
