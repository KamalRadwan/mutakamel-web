A labelled input. Always white `surface-field`, including in view mode: never gray a readable field. You provide the label, optional required mark, the hint text and the value. The hint icon is not a tab stop and its tooltip opens on the label line, never over the input. Show the validation message under the field only when present; it is the only error allowed in the page body. Use `field-h` 24px in 3 columns, `field-h-compact` 22px in 4 columns from 1280px. Phone values are LTR digits with no spaces.
